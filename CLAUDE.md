# AI Business Starter Agent

Python / FastAPI / LangChain app that helps first-time Indian entrepreneurs plan a small business.
Run tests offline with `pytest` (mock LLM is forced in tests/conftest.py).

## Git rules
- Never mention Claude, Claude Code, Anthropic or AI in commit messages, PR titles,
  PR descriptions, branch names, code comments or docs.
- No "Co-Authored-By" or "Generated with" lines anywhere.
- Commit messages: short, imperative, conventional style
  (e.g. "feat: add calculator module", "fix: handle zero profit in break-even").
- Branch names: feature/<phase>-<short-name>.
